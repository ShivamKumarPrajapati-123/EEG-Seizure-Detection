\# Dataset



This repository does \*\*not\*\* include the original CHB-MIT EEG (.edf) files because they are large.



Download the dataset from PhysioNet:



https://physionet.org/content/chbmit/1.0.0/



Place the downloaded files in:



data/chb01/
